# 東北本部 キロ程トラッカー(PWA・オフライン対応)

GPS位置を線形に投影してキロ程を推定する保線向けツールです。
GitHub Pages に置くと、圏外でも動作し、再起動後も1タップで起動できます。

## 含まれるファイル
- `index.html` … アプリ本体(全線区データを内蔵)
- `manifest.webmanifest` … アプリ情報(名前・アイコン・全画面表示)
- `sw.js` … Service Worker(オフライン動作用のキャッシュ)
- `icon-192.png` / `icon-512.png` … ホーム画面アイコン

**5ファイルすべてを同じ場所(同じフォルダ)に置いてください。** ばらばらだと動きません。

## GitHub Pages での公開手順(PCでの作業を推奨)
1. GitHub にログインし、新しいリポジトリを作成(例:`kilotracker`)。Public を選択。
2. 「uploading an existing file」から、上記5ファイルを**まとめてアップロード**して commit。
3. リポジトリの **Settings → Pages** を開く。
4. 「Build and deployment」の Source を **Deploy from a branch** にし、Branch を **main / (root)** にして Save。
5. 数分待つと、ページ上部に公開URL(`https://ユーザー名.github.io/kilotracker/`)が表示されます。

## Pixel 7(Chrome)でホーム画面に追加
1. Chrome で上記の公開URLを開く。
2. 右上 [⋮] メニュー →「ホーム画面に追加」または「アプリをインストール」。
3. 追加すると、通常のアプリのように全画面で起動します。再起動後も問題なく開けます。

## オフラインで使う
- 一度オンラインで開けば、Service Worker が全ファイルをキャッシュします。
- 以降は**圏外(トンネル・山間部)でもフル動作**します(GPS測位自体は電波不要)。
- アプリを更新したい場合は、`sw.js` の `CACHE = 'kilotracker-v1'` の番号を上げて再アップロードすると、次回オンライン起動時に更新されます。

## 注意
- 補正データは端末内(このアプリのローカルストレージ)にのみ保存されます。外部送信はありません。
- 線形出典:国土数値情報(鉄道データ N02・国土交通省)を加工。キロ程は各線の起点からの通し距離の推定値で、現地キロ程標(実キロ)とは区間差があり得ます。現地での区間補正の使用を前提としてください。
